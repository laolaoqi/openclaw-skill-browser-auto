# Browser Automation Skill Pack

## Description
Web browser automation. Control pages, fill forms, scrape data, take screenshots, automate workflows.

## Quick Install
```
openclaw skills enable browser-automation
```

## Features
- Navigate URLs and interact with pages
- Click buttons, links, form elements
- Fill inputs and submit forms
- Scrape page content
- Take screenshots
- Manage multiple tabs
- Execute JavaScript
- Monitor network requests

## Configuration
```yaml
tools:
  profile: coding
```
